⚠ Firebase Setup Required

  1. Go to console.firebase.google.com and create a project
  2. Enable Firestore Database (start in test mode)
  3. Enable Authentication → Sign-in method → Email/Password
  4. Go to Project Settings → Your apps → copy the firebaseConfig object
  5. Replace the firebaseConfig values in this file's <script> section
  6. Deploy to Netlify or GitHub Pages for full sync

ℹ App is running in offline/localStorage mode until Firebase is configured.
